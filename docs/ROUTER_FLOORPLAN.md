# 병실 평면도 · 침대 · 게이트웨이 위치 — 라우터(RP5-2) 연동 안내

에뮬레이터(RP5-1, `http://192.168.0.125:5445`)가 만든 병원 도면을 라우터 뷰어가 **그대로** 그리기 위한 안내다.
2026-09-23 릴리스 20260923-1804 기준. 값은 모두 운영 서버에서 그대로 가져온 예시다.

---

## 1. 한눈에 보기

| 알고 싶은 것 | 어디서 | 핵심 필드 |
|---|---|---|
| 병원 전체 도면 (한 번 받아 두기) | `GET /api/v1/emr/layout` | `floors[].rooms[]`, `floors[].corridors`, `gateways[]` |
| 한 층의 도면 + 지금 환자 | `GET /api/v1/emr/floors/{building_idx}/{floor}` | `rooms[]`, `gateways[]`, `patients[]`, `width`, `depth` |
| 침대 전체 목록 | `GET /api/v1/emr/beds` | `beds[]`, `bed_size_m`, `angle_deg` |
| 게이트웨이 설치 위치 + 실시간 상태 | `GET /api/v1/emr/gateways` | `x`, `y`, `z`, `mount`, `gw_no`, `status` |

**꼭 지킬 것 세 가지**
1. 침대는 **`angle` 만큼 회전**해서 그린다. 무시하면 옆벽에 가로로 놓인 침대가 방 밖·복도로 삐져나온다.
2. 게이트웨이는 **`x`·`y` 좌표 그대로** 그린다. 방 모서리에 자동 배치하면 안 된다. 병실 게이트웨이는 침대 위 천정에 있다.
3. 문은 **`door_seg`** 두 점 사이다. 복도측 벽 가운데, 폭 1.2 m.

---

## 2. 좌표계

- 단위는 **미터(m)**. 층마다 원점은 **도면 왼쪽 위**, **x 는 오른쪽**, **y 는 아래쪽**으로 증가한다 (화면·SVG 좌표와 같다).
- 층 크기는 층 API 의 `width`(x 방향), `depth`(y 방향). 예: 본관 3층 `width 60`, `depth 40`.
- 방·침대·게이트웨이·문 좌표가 모두 **같은 층 좌표계**다. 층이 다르면 `building_idx`·`floor` 로 구분한다.

## 3. 방 (`rooms[]`)

```json
{"id": "103A01", "name": "01", "kind": "room",
 "poly": [[7.6, 1.0], [15.0, 1.0], [15.0, 7.6], [7.6, 7.6]],
 "cx": 11.3, "cy": 4.3,
 "door": "S", "door_seg": [[10.7, 7.6], [11.9, 7.6]],
 "beds": [{"id": "103A01-A", "x": 8.9,  "y": 1.64, "angle": 270.0},
          {"id": "103A01-B", "x": 13.7, "y": 1.64, "angle": 90.0},
          {"id": "103A01-C", "x": 8.9,  "y": 3.8,  "angle": 270.0},
          {"id": "103A01-D", "x": 13.7, "y": 3.8,  "angle": 90.0}],
 "gateway_idx": 88}
```

| 필드 | 뜻 |
|---|---|
| `poly` | 방 외곽 다각형 (벽 중심선). 그대로 채우고 테두리를 그린다 |
| `cx`, `cy` | 방 중심 (라벨·툴팁 기준점) |
| `kind` | `room`(병실), `isolation`(격리), `er`, `exam`, `nurse_station`, `toilet`, `stairs`, `elevator` … |
| `door` | 회전 전 기준 복도를 향한 면: `N` `S` `E` `W` |
| `door_seg` | **출입문 구간** 두 끝점. 이 구간은 벽을 끊어서 그린다 (폭 1.2 m) |
| `beds` | 이 방의 침대 (§4) |
| `gateway_idx` | 이 방 게이트웨이의 행 번호 (`gateways[].idx` / `row`) |

응급실·투석실처럼 병상이 트인 공간은 `door_seg` 가 없다 (문 하나로 드나드는 방이 아님).

## 4. 침대 (`beds[]`)

- `x`, `y` = **침대 중심**, `angle` = **머리 방향(도)**.
- 크기: **폭 1.08 m × 길이 2.4 m** (`/emr/beds` 의 `bed_size_m` 에도 있다).
- 각도 기준: **0° = 머리가 위(-y)**, 시계 방향으로 증가.

| angle | 머리가 향하는 쪽 | 도면에서 모양 |
|---|---|---|
| 0 | 위 (-y) | 세로, 베개가 위 |
| 90 | 오른쪽 (+x) | **가로**, 베개가 오른쪽 |
| 180 | 아래 (+y) | 세로, 베개가 아래 |
| 270 | 왼쪽 (-x) | **가로**, 베개가 왼쪽 |

**배치 규칙** (재구성할 때마다 이 규칙으로 다시 만든다)
- 머리는 벽에 붙이고 **발은 방 가운데 통로 쪽**.
- **양옆 벽에 가로로 두 대씩, 창측(복도 반대편)부터** 채운다. 남으면 창측 벽에 좌우 대칭.
- 침대 사이는 **한 대 폭(1.08 m)** 만큼 띄운다. 문 앞 통로에는 침대가 없다.
- 1인실은 옆벽에 머리, 창측 끝.

**그리는 법** — 중심으로 옮기고, 돌리고, 가운데 기준 사각형:

```html
<!-- SVG: 미터 좌표를 그대로 viewBox 로 -->
<g transform="translate(8.9, 1.64) rotate(270)">
  <rect x="-0.54" y="-1.2" width="1.08" height="2.4" rx="0.18"/>      <!-- 침대 -->
  <rect x="-0.54" y="-1.2" width="1.08" height="0.48"/>                <!-- 베개(머리쪽) -->
</g>
```

캔버스 등에서 모서리 좌표가 필요하면:

```python
import math
def bed_corners(x, y, angle, w=1.08, l=2.4):
    a = math.radians(angle)
    ux, uy = math.cos(a), math.sin(a)          # 침대 폭 방향
    vx, vy = -math.sin(a), math.cos(a)         # 침대 길이 방향 (머리 → 발)
    pts = [(-w/2, -l/2), (w/2, -l/2), (w/2, l/2), (-w/2, l/2)]    # (-l/2 쪽이 머리)
    return [(x + px*ux + py*vx, y + px*uy + py*vy) for px, py in pts]
```

환자(패치) 표시는 침대 중심 또는 **가슴 위치 = 중심에서 머리 쪽으로 0.5 m** 에 두면 자연스럽다 (게이트웨이 위치 계산에도 이 점을 쓴다).

## 5. 출입문 (`door_seg`)

- 복도측 벽 **가운데**, 폭 **1.2 m**. 양옆 0.35 m 와 방 안쪽 2 m 는 비워 둔 통로다.
- 방 안쪽 방향은 `door_seg` 가운데 → (`cx`, `cy`).
- 그리기: 구간만큼 벽을 지우고(배경색 선), 한쪽 끝(경첩)에서 방 안쪽으로 90° 열린 문짝과 호를 그린다.

```js
// 에뮬레이터 GUI 와 같은 방식
function doorSvg([a, b], cx, cy) {
  const mx = (a[0]+b[0])/2, my = (a[1]+b[1])/2, len = Math.hypot(b[0]-a[0], b[1]-a[1]);
  let nx = cx-mx, ny = cy-my; const nl = Math.hypot(nx, ny) || 1; nx /= nl; ny /= nl;
  const ex = a[0] + nx*len, ey = a[1] + ny*len;                        // 열린 문짝 끝
  const sweep = ((b[0]-a[0])*ny - (b[1]-a[1])*nx) > 0 ? 1 : 0;
  return `<line x1="${a[0]}" y1="${a[1]}" x2="${b[0]}" y2="${b[1]}" stroke="배경색" stroke-width="0.3"/>` +
         `<path d="M ${b[0]} ${b[1]} A ${len} ${len} 0 0 ${sweep} ${ex} ${ey}" fill="none" stroke-dasharray="0.22 0.18"/>` +
         `<line x1="${a[0]}" y1="${a[1]}" x2="${ex}" y2="${ey}"/>`;
}
```

## 6. 게이트웨이 (`gateways[]`)

```json
{"idx": 88, "id": "GW-103-0088", "gw_no": 89, "type": "room", "room": "103A01", "room_idx": 119,
 "building_idx": 0, "floor": 3,
 "x": 11.3, "y": 2.72, "z": 2.7, "mount": "ceiling",
 "mac": "C4:7F:00:58:B8:48", "ip": "10.20.3.90", "capacity": 32, "status": 0, "n_conn": 4}
```

| 필드 | 뜻 |
|---|---|
| `x`, `y` | **실제 설치 지점** (층 좌표, m). 이 자리에 그린다 |
| `z` | 바닥에서의 높이 (m). 천정 설치는 **2.7** |
| `mount` | `ceiling`(천정) · `mobile`(원외 MCOT 휴대 게이트웨이 — 좌표 없음) |
| `gw_no` | **스트림 프레임 헤더의 `gw_id` 와 같은 값**. 프레임 ↔ 도면을 잇는 키 |
| `idx` / `row` | 에뮬레이터 내부 행 번호 (방의 `gateway_idx` 가 이것을 가리킨다) |
| `type` | `room`·`support`·`nurse_station`·`corridor`·`elevator`·`stairs`·`lobby`·`toilet`·`exam`·`er`·`mobile` |
| `status` | 0 정상 · 1 성능 저하 · 2 무응답 · 3 업링크 끊김(살아 있고 버퍼링 중) |

**설치 위치 규칙**
- **병실**: 침대 방향까지 보고 **환자 가슴 위치들의 무게중심 천정**. 방 중심이 아니라 침대가 모인 창측 쪽이다.
  예: 방 `103A01` 중심 y 4.3 → 게이트웨이 y **2.72**. 문 앞 1.2 m 는 피하고 벽에서 0.4 m 안쪽.
- **간호사실·로비 등 침대 없는 공간**: 공간을 긴 축으로 고르게 나눈 천정 (넓으면 여러 대).
- **복도**: 복도 중앙선을 따라 일정 간격 천정.

`/emr/layout` 의 `gateways[]` 에도 `x`·`y`·`z`·`mount` 가 있다. 층 API(`/emr/floors/...`)의 `gateways[]` 에는 `x`·`y` 만 있고, 높이는 위 규칙대로 천정 2.7 m 로 보면 된다.

## 7. 언제 다시 받아야 하나

도면·침대·게이트웨이 좌표는 에뮬레이터가 **재시작하거나 [병원·게이트웨이 재구성]** 할 때만 바뀐다. 이럴 때 `/emr/layout` 을 다시 받는다.
- 채팅 채널에 시스템 메시지 `재구축 후 전송 자동 시작 (general.autostart)`(재구성) 또는 `전송 자동 시작 (general.autostart)`(재시작)이 올라올 때 — 보낸 이 `link`, kind `system`
- 게이트웨이 연결이 한꺼번에 끊겼다가 다시 붙을 때 (재시작)
- 프레임에 **모르는 `gw_id`** 가 나타날 때 (게이트웨이 교체 → 새 `gw_no`). 이때는 `/emr/gateways` 만 다시 받아도 된다.

## 8. 흔한 실수 점검표

- [ ] 침대를 모두 세로로 그렸다 → `angle` 로 회전
- [ ] 침대가 방 밖으로 나온다 → 크기를 1.08 × 2.4 로, 중심 기준으로 그렸는지 확인
- [ ] 게이트웨이가 모든 방의 같은 모서리에 있다 → `x`·`y` 를 쓰지 않은 것
- [ ] 문이 없다 / 침대 앞에 문이 있다 → `door_seg` 로 벽을 끊었는지 확인
- [ ] 층이 섞인다 → `building_idx` + `floor` 로 거른다
- [ ] 프레임의 게이트웨이를 도면에서 못 찾는다 → 프레임 `gw_id` 는 도면의 `gw_no` 와 맞춘다 (`idx` 아님)
